# e-plantShopping

## Project Overview

e-plantShopping is a React-based plant shopping application developed as part of the IBM Full Stack Software Developer Professional Certificate.

The application allows users to browse different plants, view plant information, add products to their shopping cart, and manage their selected items.

The project demonstrates the use of React, JavaScript, Redux, and modern web development practices.

## Technologies Used

- React
- JavaScript
- Redux
- HTML
- CSS
- Vite
